## 做了什么

赛题包含交通状态、排队、物理一致性和 OD 路径流量预测。团队成员构建 V84 主体模型；在这份基线之上，我们研究了何时可以依据历史相似场景及相邻路段观测，谨慎修正“排队／不排队”的判断。

V86 最终修改 94 个排队预测格子。V87 将这些改动与 V85 的 10 个非重叠改动合并，合计修改 104 格；其余预测保持 V84 的内容。V87 是**预测改动的组合**，不是重新训练完整模型，也不是把两个版本的分数相加。

我的参与集中在研究方向整理、AI 辅助实验协作、候选结果核查和提交决策记录。原始基线模型由队友构建；本仓库不将团队成果或 AI 执行的实验写成我个人独立完成的模型。

## 学到了什么

- **局部改对，不保证整份提交涨分。** 排队指标按窗口计算 IoU，某些格子的收益会被其他窗口的损失抵消。
- **本地代理分有边界。** 官方排队真值未公开；反复查看同一批窗口会影响选择，不能把它当作独立盲测。
- **拟合可见车流，不等于找对隐藏路线。** V94 在数值和文件格式检查通过后，公榜显示大幅下降。路段总流量可以由多种不同路径组合产生，单靠可见路段计数不能识别每辆车走的路线。
- **提交验证有两层。** 完整性检查确认文件与预期改动一致；实际效果需要正式评分或独立留出数据支持。

更完整的事实与边界见 [实验记录](docs/experiment-log.md) 和 [方法与复盘](docs/method-and-lessons.md)。可用于简历的审慎表述见 [简历条目](docs/resume-entry.md)。
